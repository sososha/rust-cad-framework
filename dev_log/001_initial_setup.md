# 🛠️ Rust CAD 開発日誌 Vol.1: 爆速で「AIと作るCAD」の土台を築く

**日付**: 2025-11-22
**気分**: 🚀 最高にエキサイティング

## 🎬 始まりは「RustでCADを作りたい」という衝動

「Rust製のデスクトップアプリを作りたい。でも、ブラウザアプリみたいにAIエージェントがテストしてくれないのが辛い…」

そんな悩みから今日のセッションは始まった。
確かにそうだ。ネイティブアプリは「閉じた箱」になりがちで、AIに「ちょっとテストして」と頼むのが難しい。
でも、Rustのパフォーマンスは捨てがたい。マウスイベント、描画コマンド、ピンチインアウト…これらをAIと一緒にガシガシ作っていける環境が欲しい！

## 🚧 壁：WASMの夢と現実

最初は**「WASMにしてブラウザで動かせばいいじゃん？」**と考えた。
ブラウザならAIも操作しやすいし、既存のツールも使える。完璧な作戦に見えた。

しかし、調査を進めると雲行きが怪しくなる。
*   `bindgen` でC++ライブラリ（CADには必須級）を持ってくるのが超大変。
*   メモリ制限やスレッドの制約がきつい。

「高機能なCADを目指すなら、WASMは茨の道だ…」
ここで一度、壁にぶつかった。

## 💡 ブレイクスルー：逆転の発想「IPCサーバー」

そこで閃いたのが**「アプリの中にサーバーを埋め込む」**というアイデア。
ブラウザに合わせるんじゃなくて、**アプリの方をAIに合わせてしまえばいい！**

*   アプリ起動と同時に `localhost:9000` でWebサーバーを立ち上げる。
*   AIはそこに `POST /draw_line` とか送ればいい。
*   これならRustのネイティブ性能全開のまま、AIと会話できる！

「これだ！！」
このアーキテクチャが決まった瞬間、視界が開けた気がした。

## ⚡️ 爆速実装：Rust CAD Framework 誕生

方針が決まればあとは書くだけ。
`winit` (ウィンドウ)、`wgpu` (描画)、`egui` (UI)、そして `axum` (サーバー)。
これらを組み合わせた「最強のスターターキット」を一気に実装した。

*   **無限キャンバス**: 実装完了。パンもズームもヌルヌル動く。
*   **ツールシステム**: マウスイベントを綺麗に捌く仕組みができた。
*   **Agent Interface**: `curl` コマンド一発で線が引けた時の感動よ！

```bash
# AI「線を引くよ！」
curl -X POST http://localhost:9000/api/command ...
# -> 画面に線がシュッと現れる
```
これ、魔法みたいじゃない？

## 🎨 仕上げ：グリッドとスナップ

「でも、機能追加って大変なんでしょ？」
そんな不安を払拭するために、**グリッド表示**と**スナップ機能**を追加してみた。
結果は…**あっという間**。
レンダラーにループを足して、座標計算に `round()` を入れるだけ。
「カチッ」とグリッドに吸い付く感触。これこれ、これがCADだよ！
