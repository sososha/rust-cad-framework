# 🛠️ Rust CAD 開発日誌 Vol.2: 基本図形の実装

**日付**: 2025-11-25
**テーマ**: 作図機能の拡充（円・矩形）

## 1. 目的
これまでは「線」しか引けなかったが、CADとして最低限必要な「円 (Circle)」と「矩形 (Rectangle)」を描けるようにする。
AutoCADやJw_cadのような操作感を目指す。

## 2. 実装内容

### データ構造の拡張
`Entity` Enumに新しいバリアントを追加した。
```rust
pub enum Entity {
    Line { start: Point, end: Point },
    Circle { center: Point, radius: f32 }, // 追加
    Rect { p1: Point, p2: Point },         // 追加
}
```

### レンダリングロジック
`wgpu` の `LineList` トポロジーをそのまま活用するため、新しい図形も「線分の集合」として描画することにした。
*   **矩形**: 4本の線分に分解。
*   **円**: 64分割の多角形として近似。これくらい分割すれば、通常のズームレベルでは十分滑らかに見える。

### ツール実装
`Tool` トレイトの柔軟性が活きた。新しい構造体を作り、マウスイベントの処理を書くだけで追加できた。
*   **CircleTool**: 中心をクリック→ドラッグで半径決定。
*   **RectTool**: 始点をクリック→ドラッグで対角点を決定。

### Agent API
AIエージェントからもこれらの図形を描けるように、コマンドを追加した。
*   `draw_circle`: 中心座標と半径を指定。
*   `draw_rect`: 対角2点を指定。

## 3. 振り返り
フレームワークの設計（`Entity` 列挙型と `Renderer` の分離）が功を奏し、既存コードをほとんど壊さずに機能追加ができた。
特にレンダラー部分では、クロージャを使って描画ロジックを共通化し、コードの重複を防げたのが良かった。
