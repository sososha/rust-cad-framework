# 🛠️ Rust CAD 開発日誌 Vol.3: Jw_cadへの道（複線・2線）

**日付**: 2025-11-25
**テーマ**: 高度な作図機能（Double Line & Offset）

## 1. 目的
Jw_cadの強力な機能である「複線 (Offset)」と「2線 (Double Line)」を実装し、実用的なCADに近づける。
これらは単なる「線」ではなく、幾何学的な計算（ベクトル演算）が必要になるため、フレームワークの真価が問われる。

## 2. 実装内容

### ベクトル演算の導入
平行線を計算するには「法線ベクトル」が必要になる。
`Point` 構造体に以下のメソッドを追加し、ベクトル演算を可能にした。
*   `sub`: ベクトル差分
*   `normalize`: 正規化（長さ1にする）
*   `normal`: 垂直ベクトル（90度回転）
*   `scale`: スカラー倍

### プレビュー機能の強化
これまでは「1本の線」しかプレビューできなかったが、2線ツールでは「2本の線」を同時にプレビューする必要がある。
そこで `GeometryStore` の `temp_entity` (Option) を `temp_entities` (Vec) に変更した。
これにより、複雑なツールのプレビューが可能になった。

### Double Line Tool (2線)
*   始点と終点から方向ベクトルを計算し、法線方向に `width/2` ずつずらした2本の線を生成。
*   壁や配管を描くのに非常に便利。

### Offset Tool (複線)
*   **選択ロジック**: `find_nearest_entity` を実装し、マウス近くの線を特定できるようにした。
*   **インタラクション**: Jw_cadの「数値入力」方式ではなく、現代的な「ドラッグで距離決定」方式を採用。
    *   線をクリック → ドラッグで好きな距離に配置 → 離して確定。
    *   直感的で気持ちいい操作感になった。

## 3. 振り返り
「ベクトル演算」と「複数プレビュー」という基盤ができたことで、今後の機能拡張（ポリラインの太さ処理や、複雑な図形編集）が容易になった。
特にOffsetツールは、CADにおいて「作図」以上に重要な「編集・複製」の第一歩であり、大きな進歩だ。

次は、いよいよ「選択して削除」や「コーナー処理」など、図形を整理する機能に進みたい。
