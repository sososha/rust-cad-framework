# 🛠️ Rust CAD 開発日誌 Vol.4: 描いて、消して、また描いて

**日付**: 2025-11-25
**テーマ**: 編集の基本（削除）と自由な線（Polyline）

## 1. 目的
「描くだけ」のCADから脱却し、「消す」機能を実装する。
また、単調な直線だけでなく、自由な形状を描ける「連続線 (Polyline)」を追加し、表現力を高める。

## 2. 実装内容

### Delete Tool (消去)
*   **シンプルイズベスト**: 複雑な選択モードを作る前に、「クリックしたら消える」という直感的なツールを作成。
*   **実装**: `find_nearest_entity` で特定したインデックスを `Vec::remove` で削除。
    *   *注意点*: インデックスがずれる問題があるが、単発の削除なら問題ない。将来的にID管理が必要になるかも。

### Polyline Tool (連続線)
*   **データ構造**: `Entity::Polyline { points: Vec<Point> }` を追加。
*   **レンダラー**: 点のリストを順番に線で結ぶロジックを追加。
*   **操作性**:
    *   クリックで点を追加。
    *   **終了判定**: 「最後の点の近くでもう一度クリック」で終了。ダブルクリックのような感覚で直感的に操作できる。

## 3. 振り返り
「消去」機能が入ったことで、間違えてもやり直せる安心感が生まれた。これはデモやテストをする上で心理的に非常に大きい。
Polylineも、矩形や円では表現できない形状を描けるため、CADとしての「自由度」が一気に上がった。

次は、線同士を綺麗につなぐ「コーナー処理 (Trim/Extend)」に挑戦したい。これができれば、プロっぽい図面が描けるようになるはずだ。
