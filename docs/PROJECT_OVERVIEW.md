## 1. プロジェクトの正体 (What are we building?)

### 🎯 開発するCADのタイプ
**「モダンで高性能な 2D 汎用 CAD」** です。

- **イメージ**: AutoCAD LT や LibreCAD を、現代の技術（Rust + GPU）で再構築したもの。
- **用途**: 建築図面、機械設計（2D）、電子回路図など。
- **アーキテクチャ**: **Document-View パターン**
  - データ（図面）と表示（ビュー）を完全に分離し、堅牢性と拡張性を確保します。

### ✨ 主な特徴 (Key Features)
1. **圧倒的なパフォーマンス**
   - **Rust + WGPU**: GPUアクセラレーションをフル活用し、10万オブジェクトでも60FPSで動作。
   - **メモリ効率**: Structure of Arrays (SoA) レイアウトでキャッシュ効率を最大化。

2. **堅牢な設計 (Multi-Crate)**
   - **モジュラー構造**: `core` (データ), `rendering` (描画), `tools` (操作) を独立したクレートとして管理。
   - **VS Codeライク**: 将来的にプラグインで機能を拡張できる基盤。

3. **AIネイティブ**
   - **AI操作性**: すべての操作がコマンドとして定義されており、AIエージェントがテストや操作を行いやすい設計。

## 2. 開発戦略 (How do we build it?)

### 🏗️ 採用する戦略: Vertical Slice + Multi-Crate

従来の「レイヤーごと（データ層→描画層→UI層）」ではなく、**「機能ごと（垂直スライス）」** に開発を進めます。

#### なぜこの戦略か？
- **常に動くソフトウェア**: 「線を引く」という機能を、データ・描画・操作の全層で一気に実装します。
- **モチベーション維持**: 早期に画面で動作を確認できます。
- **手戻りの防止**: 全層を通すことで、APIの不整合を早期に発見できます。

### 📦 ファイル/クレート構成 (Cargo Workspace)

モノリスではなく、最初から **Workspace構成** で始めます。

```
my-cad/
├── Cargo.toml (Workspace定義)
├── apps/
│   └── desktop/       # 実行用アプリ (GUI)
└── crates/
    ├── cad-core/      # データ構造・計算 (依存なし)
    ├── cad-rendering/ # WGPUレンダラー
    ├── cad-tools/     # ツールロジック
    ├── cad-ui/        # egui UIコンポーネント
    └── cad-io/        # ファイル入出力
```

## 3. 開発フェーズ (Phases)

### Phase 0: Project Setup (土台作り)
- **目標**: 黒い画面に「白い十字線」が表示される。
- **内容**: Workspace作成、ウィンドウ表示、WGPU初期化。
- **意味**: 開発環境とレンダリングパイプラインの開通確認。

### Phase 1: Core Foundation (線の実装)
- **目標**: コードで定義した「線」と「円」が画面に描画される。
- **内容**: `cad-core` (データ), `cad-rendering` (描画) の実装。
- **意味**: データ構造と描画システムの結合。

### Phase 2: Tool System (マウス操作)
- **目標**: マウスでドラッグして線を引ける。
- **内容**: `cad-tools` (State Machine), イベント処理の実装。
- **意味**: ユーザーインタラクションの実装。

### Phase 3: UI Integration (ツールパレット)
- **目標**: ボタンでツール（線・円）を切り替えられる。
- **内容**: `cad-ui` (egui), ツールマネージャーの統合。
- **意味**: アプリケーションとしての体裁を整える。

### Phase 4: Persistence (保存・読み込み)
- **目標**:描いた図面をファイルに保存し、再起動して開ける。
- **内容**: `cad-io` (JSON/DXF), シリアライズの実装。
- **意味**: 実用的なツールとしての完成。

## 4. 成功の定義 (Definition of Done)

このプロジェクトは、以下の状態になった時点で「成功」とみなします：

1. **起動**: 1秒以内に起動する。
2. **操作**: マウスで線、円、ポリラインをスムーズに描ける。
3. **編集**: 描いた図形を選択し、移動・削除できる。
4. **保存**: 作業内容をファイルに保存し、復元できる。
5. **品質**: 1万本の線を描いてもスクロールがカクつかない。
